    📄 大模型系统性能优化：CUDA、FlashAttention 与 Triton 算子实战¶

    📖 课程简介¶

    这门课程专为追求极致性能的 AI 工程师打造，旨在解决大语言模型在训练和推理阶段面临的算力瓶颈与显存墙挑战。通过深入底层硬件与核心算子优化，帮助开发者突破框架封装，从根本上提升模型的运行效率与吞吐量。

    课程从 CUDA C++ 与 Numba CUDA 硬件底层编程 出发，深入剖析 FlashAttention 机制的数学推导与手写实现，并全面掌握现代 GPU 编程利器 Triton 算子开发。课程涵盖 GPU 架构原理、算子融合、高效内存存取模式到 PyTorch 自定义算子无缝集成的完整系统性能优化闭环。

    课程的意义与作用¶

    • 击破底层性能瓶颈：不再依赖通用的框架层优化，而是直接从 GPU 硬件架构、SRAM 缓存调度、寄存器分配和显存访存（如 Global Memory 到 Shared Memory 的高效加载）切手，榨干硬件的每一滴算力。
    • 攻克核心注意力机制：透彻理解并从零手写 FlashAttention（1/2），彻底消除标准 Attention 在显存中生成庞大 N \times N 注意力矩阵的显存暴涨问题，将显存复杂度从 O(N^2) 降低至 O(N)。
    • 掌握现代高阶算子开发工具：熟练运用 Triton 语言进行 GPU 算子编程，摆脱繁琐冗长的底层 CUDA C++ 代码编写，以接近 Python 的开发效率编写出媲美甚至超越手写 CUDA 的高性能算子。
    • 打通端到端工程落地闭环：不仅停留在理论推导与玩具代码，而是掌握如何将自定义的高性能算子安全、高效地注册并集成回 PyTorch 中，直接赋能大模型的前向与反向推理/训练生产环境。

    与实际工作的紧密联系¶

    在当前大模型与多模态模型走向大规模落地（如万亿参数预训练、长文本推理、高并发低延迟 Serving）的背景下，系统优化能力已成为高级 AI 工程专家的核心竞争力：

    1. 大模型全栈训练与微调加速：在进行 Qwen、LLaMA 等大模型及多模态模型的预训练或全参数微调时，自定义算子与算子融合（如 FlashAttention、Fused RMSNorm、Rotary Embedding 优化）能够显著降低显存占用，从而允许开箱使用更大的 Batch Size 与更长的 Context Length，直接缩短训练周期并降低集群算力成本。
    2. 推理服务（Serving）吞吐与延迟优化：在生产环境中部署 vLLM 等高性能推理框架或自研推理后端时，经常需要针对特定的网络结构或量化方案（如 INT4/FP8 混合精度）开发定制化的 Triton 或 CUDA 算子，以消除 Kernel 频繁启动的开销，提升 GPU 利用率。
    3. 解决棘手的生产环境性能瓶颈：当面对显存溢出（OOM）、算子执行效率低下、GPU 算力利用率（MFU）上不去等深层次架构痛点时，具备从 CUDA 硬件执行模型到 Triton 脚本调优的排查与实现能力，能够让你快速定位并从底层重构性能热点。

    🚀 全程学习路径¶

    🏗️ 第一章：CUDA 编程¶

    • 1.1 GPU发展史：回顾 GPU 从图形渲染走向通用并行计算的发展脉络与演进趋势。
    • 1.2 算术运算vs逻辑运算：剖析底层硬件指令执行模型与计算单元的差异。
    • 1.3 并行计算：理解并行计算基本范式、任务划分与硬件映射原理。
    • 1.4 CUDA程序的基本结构：掌握 C++ 与 Numba CUDA 主机/设备端代码编写规范、Kernel 启动配置与线程层次模型。
    • 1.5 多维网格和矩阵乘法：探索 Grid/Block 维度组织方式及其在基础矩阵乘法中的应用。
    • 1.6 计算架构和调度：深入 SM 硬件架构、Warp 调度机制与指令吞吐优化。
    • 1.7 CUDA的内存管理：精讲全局内存、共享内存、寄存器及内存对齐与访问合并。
    • 1.8 矩阵乘法优化：利用 Shared Memory 缓存与分块技术实现高性能矩阵乘法。
    • 1.9 规约：实现高效的并行归约（Reduction）算法与 Warp 级 Shuffle 优化。

    🧠 第二章：Triton 编程¶

    • 2.1 使用Triton实现向量加法：上手 OpenAI Triton 声明式编程模型，快速编写第一个 Triton Kernel。
    • 2.2 Triton Puzzles：通过趣味编程挑战深入理解 Triton 块指针与索引机制。
    • 2.3 Fused Softmax：实现算子融合，消除中间显存读写开销。
    • 2.4 用Triton实现矩阵乘法：基于 Triton 编写高效的 Block-level GEMM 算子。
    • 2.5 Layer Normalization：实现数值稳定且高效的层归一化融合算子。
    • 2.6 Triton与torch.compile：探索 Triton 与 PyTorch Inductor 图编译器的深度集成。
    • 2.7 大模型高性能算子实战：基于 Triton 实现 SwiGLU 融合算子：生产级 SwiGLU 融合算子全流程开发与性能评测。

    ⚡ 第三章：从零实现FlashAttention¶

    • 3.1 Transformer的Attention计算：分析标准 Attention 的 O(N^2) 显存访存瓶颈。
    • 3.2 Online Softmax算法：掌握增量 Softmax 的数学推导与分块计算原理。
    • 3.3 使用算子融合加速未softmax的Attention：通过 Kernel 融合减少 HBM 访问。
    • 3.4 用CUDA实现FlashAttention V1：手写 CUDA (C++/Numba) 实现 FlashAttention-1 前向传播。
    • 3.5 用CUDA实现FlashAttention V2：手写 CUDA (C++/Numba) 实现 FlashAttention-2 前向传播。
    • 3.6 用Triton实现FlashAttention前向算法：使用 Triton 优雅实现高性能 FlashAttention 前向算子。

    • 附录2 Tensor Layout：深入理解张量内存布局、Stride 与连续性。

    • 附录5 CUDA Stream和异步架构：利用多流并发与异步拷贝提升流水线效率。
    • 附录6 FlashAttention论文解读：精读 FlashAttention 原始经典论文。
    • 附录7 FlashAttention-2论文解读：深入解析 FlashAttention-2 的架构改进与加速点。
    • 附录8 用CUDA实现MHA的FlashAttention V1/V2：扩展支持多头注意力（MHA）的 CUDA 实现。

    🛠️ 核心技术栈¶

    ⚡ 编程语言与硬件架构¶

    • 底层语言: CUDA C/C++, Numba CUDA (Python), C++17/20
    • GPU 架构特性: Shared Memory, Bank Conflict Avoidance, Warp Shuffle Functions, Tensor Cores, Asynchronous Copy
    • Python 领域 DSL: OpenAI Triton (triton.jit, Block Pointer Parsing), Numba (cuda.jit, cuda.shared.array)

    🧠 算子与算法优化¶

    • 核心算子: FlashAttention v1/v2 (Forward & Backward), Fused Softmax, Layer Normalization, Gemm, Reduction, SwiGLU
    • 算法与数学: Online Softmax (Safe/Online Scaling), Tiled Matrix Multiplication, Matrix Transpose & Layouts

    🚀 框架与工程集成¶

    • PyTorch 生态: LibTorch, PyTorch Custom C++/CUDA Operator Extension (torch.library), torch.compile (Inductor Backend)
    • 开发与构建: C++ / Python 协同, WSL2/Ubuntu CUDA 环境

    📝 学习须知¶

    1. 动手实操: 本课程强依赖代码手写与 Performance Benchmark 基准测试，每一章均提供对应的项目代码与 C++/Numba/Triton 练习，建议边学边手动编译运行。
    2. 环境一致性: 涉及 CUDA Kernel 编译与 GPU 硬件特性（如 Tensor Core），建议在配置有 NVIDIA GPU 的 Linux（或 WSL2 + Ubuntu）环境下运行。
    3. 公式与图解: 本文档使用 MathJax 渲染 Attention 分块推导与 Online Softmax 更新公式，若公式渲染异常，请刷新页面或检查网络。
