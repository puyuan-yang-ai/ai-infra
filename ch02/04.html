    Online Softmax算法¶

    学习目标¶

    • 理解Safe Softmax和Online Softmax的原理
    • 代码实现Safe Softmax和Online Softmax

    1. Softmax函数简介¶

    Softmax 是一种将任意实数向量映射为概率分布的激活函数，常用于多分类神经网络的输出层以及 Transformer 架构中的注意力权重计算。

    给定一个含有 K 个实数的向量 z = [z_1, z_2, \dots, z_K]^T，Softmax 函数的第 i 个分量定义为：

    \text{Softmax}(z)_i = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}

    为什么要弄成这么奇怪的一个函数？

    把任意实数（可正可负、可大可小的 logits）转换为合法的概率分布，本质上是一个“加约束的数学映射”过程。Softmax 函数的诞生，正是为了完美满足这三个核心诉求：

    一、 必须非负：引入指数函数

    原始的神经网络输出 z_i 可以是任意实数，但概率论的基本公理要求概率不能为负。为了将全实数域 \mathbb{R} 映射到正数区间 (0, +\infty)，最自然且数学性质优良的选择就是 指数函数 e^{z_i}。因为对任意实数 x，恒有 e^x > 0。这不仅天然排除了负概率，也避开了绝对值函数在零点不可导、或二次函数丢失正负方向等缺陷，同时指数函数处处光滑可导。

    二、 必须归一化：分母求和

    经过指数变换后得到的一组数 e^{z_1}, e^{z_2}, \dots, e^{z_K} 虽然全部大于 0，但它们的总和并不等于 1，无法直接当作概率。为了满足“所有互斥事件概率之和等于 1”的归一化公理，最直接的办法就是 除以所有项的总和 ：

    p_i = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}

    分母的全局累加求和将整体尺度锁定，强制让所有输出的总和严格等于 1。

    三、 保持单调性：确保大者恒大

    概率映射不能颠倒原本的相对大小关系——如果原本模型更倾向于类别 i（即 z_i > z_j），那么转换后的概率也必须满足 p_i > p_j。这一特性由指数函数的 严格单调递增性 天然保证：若 z_i > z_j，则必然有 e^{z_i} > e^{z_j}。在同除以一个相同的正数分母后，分子的大小顺序被完美保留。同时，指数函数的非线性增长特性还会进一步拉开差距，让原本领先的类别获得更具压倒性的概率优势。

    1.1 核心特性¶

    • 概率归一化： 输出向量的所有元素均在 (0, 1) 区间内，且所有元素的总和严格等于 1 (\sum_{i=1}^K \text{Softmax}(z)_i = 1)。
    • 放大差异（Winner-Take-All）： 由于指数函数的非线性增长特性，Softmax 会显著拉开输入向量中较大值与较小值之间的相对差距。输入中最大的那个元素在经过 Softmax 后会获得压倒性的概率占比。
    • 平移不变性： 对输入向量的所有元素同时加上或减去同一个常数 C，Softmax 的输出结果保持不变：
    \text{Softmax}(z)_i = \frac{e^{z_i - C}}{\sum_{j=1}^{K} e^{z_j - C}}

    1.2 带温度的Softmax¶

    1.2.1 基本概念¶

    Softmax 可以引入温度参数（Temperature，T），通常称为 Temperature-scaled Softmax。

    引入温度参数后的公式为：

    \text{Softmax}(z_i; T) = \frac{e^{z_i / T}}{\sum_{j=1}^{K} e^{z_j / T}}

    其中 T > 0 为温度系数。它的核心作用是通过缩放 logits 来调节概率分布的“尖锐程度”：

    • 当 T = 1 时： 退化为标准的 Softmax。
    • 高温区（T > 1）： 输入的 logits 会被压缩，导致指数计算后的数值差异变小。输出的概率分布会变得更 平坦（Flatter），各类别之间的概率差距缩小，随机性和多样性增加。
    • 低温区（T \to 0）： 输入的 logits 会被放大，最大的那个值会具有压倒性优势。输出的概率分布会变得极度 尖锐（Sharp），最高概率的类别趋近于 1，其余趋近于 0（退化为 Hardmax / Argmax）。

    1.2.2 典型应用场景¶

    • 大语言模型文本生成（Sampling）： 调节模型的“创造力”与“确定性”。高温度（如 T > 0.8）让模型生成更多样、更有创意的文本；低温度（如 T < 0.3）让输出更严谨、更具确定性（常用于代码生成或事实问答）。
    • 知识蒸馏（Knowledge Distillation）： 在将大模型的知识迁移给小模型时，使用较高的温度来平滑教师模型的输出，从而让小模型学习到非目标类别之间的“暗知识（Dark Knowledge）”（例如猫和狗有一定的相似概率，而和汽车概率无关）。
    • 对比学习（Contrastive Learning）： 在 InfoNCE 等对比损失函数中，温度参数用于调节对困难负样本（Hard Negatives）的惩罚力度。

    1.2.3 为什么T \to 0时退化为Argmax？¶

    第 i 个元素的带温度 Softmax 公式为：

    p_i = \frac{e^{z_i / T}}{\sum_{j=1}^{K} e^{z_j / T}}

    设 z_m 为 logits 向量中的最大值，即 z_m = \max_j z_j。为了分析 T 变小时的行为，我们将分子和分母同除以 e^{z_m / T}：

    p_i = \frac{\frac{e^{z_i / T}}{e^{z_m / T}}}{\sum_{j=1}^{K} \frac{e^{z_j / T}}{e^{z_m / T}}} = \frac{e^{(z_i - z_m) / T}}{\sum_{j=1}^{K} e^{(z_j - z_m) / T}}

    现在，我们来观察每个元素的指数项 (z_j - z_m) / T 在 T \to 0^+ 时的变化：

    1. 对于最大值元素（z_i = z_m）： 指数项为 \frac{z_m - z_m}{T} = 0，因此该项的值为 e^0 = 1。
    2. 对于任意非最大值元素（z_j < z_m）： 因为 z_j < z_m，所以差值 \Delta_j = z_m - z_j 严格大于 0（\Delta_j > 0）。指数项变为 -\frac{\Delta_j}{T}。当 T \to 0^+ 时，-\frac{\Delta_j}{T} \to -\infty，这意味着对应的指数项 e^{-\Delta_j / T} \to 0。

    将这些极限结果代回分式中：

    • 如果 i 对应的是唯一的最大值（z_i = z_m）：
    \lim_{T \to 0^+} p_i = \frac{1}{1 + \sum_{j \neq m} 0} = 1
    • 如果 i 对应的是任何非最大值（z_i < z_m）：
    \lim_{T \to 0^+} p_i = \frac{0}{1 + \sum_{j \neq m} 0} = 0

    当 T 趋近于 0 时，除以一个极小的温度相当于将 logits 之间的微小差距无限放大。最大的那个 logit 在分母中占据了绝对主导地位，使得它自己的概率趋近于 1，而其他所有元素的概率全部被压塌归零。

    注（关于存在多个相同最大值的情况）： 如果有多个元素同时拥有并列的最大值，这些最大值元素的指数项都会是 e^0 = 1，分母会求和出并列的最大值个数。此时概率会在这些并列最大值之间平分（例如如果有两个最大值并列，各自的概率为 0.5），这与标准的 argmax 行为完全一致。

    1.4 Softmax函数的导数¶

    Softmax 函数将一个向量 \mathbf{z} 映射为概率分布 \mathbf{a}。其第 i 个分量的定义为：

    a_i = \frac{e^{z_i}}{\sum_{k=1}^{n} e^{z_k}}

    我们需要求 \frac{\partial a_i}{\partial z_j}。根据 i 是否等于 j，分为两种情况使用 商法则：

    1.4.1 情况 A：i = j¶

    \begin{aligned} \frac{\partial a_i}{\partial z_i} &= \frac{e^{z_i} \sum e^{z_k} - e^{z_i} e^{z_i}}{(\sum e^{z_k})^2} \\ &= \frac{e^{z_i}}{\sum e^{z_k}} - \left(\frac{e^{z_i}}{\sum e^{z_k}}\right)^2 \\ &= a_i(1 - a_i) \end{aligned}

    1.4.2 情况 B：i \neq j¶

    \begin{aligned} \frac{\partial a_i}{\partial z_j} &= \frac{0 \cdot \sum e^{z_k} - e^{z_i} e^{z_j}}{(\sum e^{z_k})^2} \\ &= - \frac{e^{z_i}}{\sum e^{z_k}} \cdot \frac{e^{z_j}}{\sum e^{z_k}} \\ &= -a_i a_j \end{aligned}

    1.4.3 统一形式¶

    使用 Kronecker delta 符号 \delta_{ij}（当 i=j 时为 1，否则为 0）：

    \frac{\partial a_i}{\partial z_j} = a_i(\delta_{ij} - a_j)

    1.4.4. 配合 Cross-Entropy Loss 的梯度¶

    在分类任务中，交叉熵损失函数的定义为：

    L = -\sum_{k} y_k \log(a_k)

    其中 y 是 one-hot 编码的真实标签（只有目标类别 c 处 y_c=1，其余为 0）。因此 L = -\log(a_c)。

    我们要求损失 L 对逻辑值（logits）z_i 的梯度 \frac{\partial L}{\partial z_i}，根据链式法则：

    \frac{\partial L}{\partial z_i} = \sum_{j} \frac{\partial L}{\partial a_j} \frac{\partial a_j}{\partial z_i}

    由于 L = -\sum y_j \log(a_j)，则 \frac{\partial L}{\partial a_j} = -\frac{y_j}{a_j}。代入导数：

    \begin{aligned} \frac{\partial L}{\partial z_i} &= \sum_{j} \left( -\frac{y_j}{a_j} \right) a_j(\delta_{ji} - a_i) \\ &= \sum_{j} -y_j(\delta_{ji} - a_i) \\ &= -\sum_{j} y_j \delta_{ji} + \sum_{j} y_j a_i \end{aligned}

    利用 one-hot 的性质 \sum y_j = 1 以及 \sum y_j \delta_{ji} = y_i：

    \frac{\partial L}{\partial z_i} = a_i - y_i

    1.4.5 总结¶

    物理含义 数学表达式
    Softmax 自身导数 \frac{\partial a_i}{\partial z_j} = a_i(\delta_{ij} - a_j)
    CE Loss 组合梯度 \frac{\partial L}{\partial \mathbf{z}} = \mathbf{a} - \mathbf{y}

    关键点： 最终的梯度形式极其简洁，就是 预测值与真实值之差。这就是为什么 Softmax 和交叉熵是“天作之合”，它在数学上极大地简化了反向传播的计算。

    1.5 Gumbel-Softmax 技巧¶

    Gumbel-Softmax 是一种在深度学习中用来 解决离散采样不可导问题 的技术。它是 Gumbel-Max 技巧的连续可微近似版本。

    要理解为什么需要它，我们需要先看一个痛点：在神经网络中，如果我们想从模型输出的概率分布中进行 离散采样（例如让大模型选出一个具体的词，或者在强化学习中选择一个动作），最直接的做法是使用 Argmax 或分类采样（Categorical Sampling）。但这两个操作是 阶跃函数，其导数在几乎所有地方都为 0，在跳变点处甚至不存在，这会导致梯度无法反向传播，神经网络无法通过强化学习或端到端的方式直接对离散决策过程进行优化。

    Gumbel-Softmax 的出现就是为了打通这个障碍。它分为两步：

    1.5.1. 基础：Gumbel-Max 技巧（无偏离散采样）¶

    在计算机中，如果我们想根据一组概率（对应 logits 向量 z = [z_1, z_2, \dots, z_K]）来无偏地采样出一个离散的类别，有一个优雅的数学技巧叫 Gumbel-Max：

    \text{arg}\max_i \left( z_i + g_i \right)

    其中 g_i 是从 Gumbel 分布（Gumbel(0, 1)）中独立同分布随机抽样出来的噪声。生成 Gumbel 噪声很简单，只需先对均匀分布噪声 u \sim \text{Uniform}(0, 1) 取两次对数：g = -\log(-\log(u))。 这个公式神奇的地方在于：直接对加了噪声的 logits 取 argmax，其结果的概率分布完全等价于直接按 Softmax 概率进行多项式采样。 这样我们就把随机采样过程转化成了带有随机噪声的确定性最大值选择。

    1.5.2. 核心：引入 Softmax 和温度进行连续松弛¶

    argmax 依然是不可导的。Gumbel-Softmax 的核心创新，就是用 带温度参数的 Softmax 替换掉不可导的 argmax：

    y_i = \frac{\exp\left( \frac{z_i + g_i}{T} \right)}{\sum_{j=1}^{K} \exp\left( \frac{z_j + g_j}{T} \right)}

    通过这个替换，魔法发生了：

    • 保持可导： 因为使用了处处光滑连续的 Softmax，整个操作变成了关于 logits z 的可微函数。梯度可以通过这个模块正常反向传播，神经网络可以愉快地用梯度下降进行端到端训练。
    • 逼近离散： 训练时引入温度 T。当 T 较高时，输出是一个平滑的概率分布，方便梯度流动；随着训练进行，逐渐将 T 降低（Annealing，T \to 0）。当 T 趋近于 0 时，输出的向量 y 会极端趋近于一个 One-hot 独热编码（即某个分量趋近于 1，其余趋近于 0），完美退化回硬编码的离散选择。

    1.5.3 典型应用场景¶

    • 变分自编码器（VAE）中的离散潜变量： 当模型的隐空间（Latent Space）需要包含类别型、离散型的特征而非连续高斯分布时。
    • 强化学习（RL）与策略梯度： 在动作空间是离散的情况下，通过 Gumbel-Softmax 可以让策略网络进行端到端的平滑优化。
    • 神经网络架构搜索（NAS）与 Token 剪枝： 在模型需要动态决定保留哪些路径、哪些 Token 或哪些子模块时，用它来进行可微的离散门控（Gate）选择。

    2. Naive Softmax实现¶

    实现一个Softmax看起来非常简单：

    // 计算 e^(x_i) 并求和

# ==========================================
def unsafe_softmax(x):
    # 转换为 numpy 数组
    arr = np.array(x, dtype=np.float32)

    # 计算 e^(x_i) 并求和
    exp_x = np.exp(arr)  # 如果 arr[i] >= 89，直接产生溢出警告并变为 Inf！

    # 归一化 (Inf / Inf -> NaN)
    return exp_x / sum_exp

    这段代码实现了一个 朴素的Softmax 算法。它直接按照数学公式进行计算，但在计算机浮点数的有限精度下，极易引发上溢（Overflow）并产生 NaN。

    代码的执行逻辑分为两个核心步骤：

    1. 指数与求和： 遍历输入向量 x，计算每个元素的指数 e^{x_i} 并累加到 sum_exp 中。
    2. 归一化： 将每一个指数项除以总和 sum_exp 得到概率。

    为什么这段代码“不安全”？

    • 数值上溢（Overflow）产生 Inf： 在单精度浮点数（float）标准下，能表示的最大正数约为 3.4 \times 10^{38}，对应的指数上限约为 e^{88.72}。如果输入的某个 x_i \ge 89（例如 100），std::exp(100) 会超出 float 范围，直接变成正无穷（Inf）。
    • Inf / Inf 导致 NaN 坍塌： 一旦某个 x_i 触发上溢，累加和 sum_exp 也会变成 Inf。在接下来的归一化循环中，result[i] / sum_exp 就会变成 Inf / Inf，其结果在 IEEE 754 浮点标准下是 NaN（Not a Number），导致整个向量的计算结果全部失效。

    3. Safe Softmax实现¶

    3.1 解决思路¶

    根据softmax的平移不变性，我们可以给向量的每一个元素都减去一个固定的值，那么softmax的结果不变。

    但是这个值怎么选呢？如果太大（例如选了一个远大于最大值的常数），所有的 x_i - C 都会变成绝对值极大的负数，导致 e^{x_i - C} 全部趋近于 0（发生 下溢（Underflow）），最终分母为 0 导致计算崩溃；如果太小（例如选 0 或不够大），遇到较大的原始输入时依然无法阻止指数暴增，从而发生上溢（Overflow）产生 Inf。比较好的选择是输入向量的 最大值。

    为什么选择输入向量的最大值 M = \max(x)？

    选择 M = \max(x) 作为平移常数是最优解，原因在于它在数学上完美锁定了指数的上限区间：

    1. 绝对杜绝上溢（Overflow）： 对于原向量中的最大值，减去自身后指数项变为 e^{\max(x) - \max(x)} = e^0 = 1。对于其余所有非最大值元素，由于 x_i < \max(x)，其差值 x_i - \max(x) 恒为负数，对应的指数项 e^{x_i - \max(x)} 严格处于 (0, 1) 区间内。这意味着 所有指数项都被死死压制在了不大于 1 的范围内，彻底消除了上溢风险。
    2. 安全容忍下溢（Underflow）： 如果某个元素比最大值小太多（例如 x_i \ll \max(x)），其指数项确实会因为 x_i - \max(x) 极度负向而下溢为 0.0f。但在计算机浮点数运算中，指数项下溢为 0 是完全无害的——它在求和时只贡献 0，不会污染最终结果，也不会产生 NaN。

    std::vector<float> safe_softmax(const std::vector<float>& x) {
    if (x.empty()) return {};

    std::vector<float> result(x.size());

    // 第一步：找到输入向量中的最大值 x_max
    float max_val = *std::max_element(x.begin(), x.end());

    // 第二步：计算 e^(x_i - x_max) 并求和
    float sum_exp = 0.0f;
    for (size_t i = 0; i < x.size(); ++i) {
        result[i] = std::exp(x[i] - max_val); // 指数上限被限制为 e^0 = 1.0，绝不溢出
        sum_exp += result[i];
    }

    // 第三步：归一化
    for (size_t i = 0; i < x.size(); ++i) {
        result[i] /= sum_exp;
    }

    return result;
}

    # 第三步：归一化
    return exp_x / sum_exp

    3.4 Safe Softmax带来的问题¶

    传统 Safe Softmax 虽然通过先求最大值消除了上溢风险，但它付出的代价是破坏了单遍扫描（Single-pass）的流水线性质。标准的 Safe Softmax 在实际执行时通常需要对数据进行 2 到 3 次完整的遍历：

    1. 第 1 遍遍历： 读取输入向量，扫描并找出最大值 M。
    2. 第 2 遍遍历： 再次读取输入向量，减去 M，计算指数并累加求和得到分母 S。
    3. 第 3 遍遍历（或隐式结合在第 2 遍）： 读取指数项，除以 S 得到最终的概率输出。

    在现代 GPU 架构和高性能计算中，这种多遍扫描引发了严重的性能瓶颈，其核心根源在于 内存墙（Memory Wall）。

    3.4.1 为什么多遍扫描在 CUDA 中是一个大问题？¶

    • 算子属于“访存密集型（Memory-Bound）”而非“计算密集型”： Softmax 的数学运算非常简单（主要是减法、指数和除法），GPU 强大的浮点计算能力（TFLOPS）在它面前根本吃不饱。它的实际运行速度完全取决于 数据在显存（HBM）中的搬运速度。
    • 灾难性的显存带宽浪费（Global Memory Round-trips）： GPU 的高带宽内存（HBM）吞吐量虽然很高，但延迟也大。多遍扫描意味着算法必须不断地“从 HBM 读数据 \to 算一点结果 \to 写回 HBM \to 下一轮又从 HBM 重新读出来”。每一次中间结果（如中间的指数、临时的和）落盘到全局显存再读出，都在无谓地吞噬宝贵的显存带宽。
    • 无法实现优雅的算子融合（Kernel Fusion）： 在 CUDA 编程中，最高效的内核是“输入一次读入寄存器/共享内存，在片上处理完毕后直接输出”。多遍扫描强制将计算拆成了多个独立的 Kernel（或者在同一个 Kernel 里加了同步栅栏），导致线程块不得不频繁等待全局显存的读写同步。

    特别是在大语言模型的 Transformer 注意力机制中，输入矩阵极其巨大（如 N \times N 的 Attention Score 矩阵）。如果每次计算 Softmax 都要在 HBM 和 SRAM 之间反复折腾 3 次，显存带宽会瞬间被占满，成为整个模型训练与推理的严重性能拖累。

    4. Online Softmax¶

    Online Softmax希望把前面的两趟合并成一趟，也就是遍历一趟x，同时求出最大值m以及指数和l。

    4.1 从一个例子得到启发¶

    输入序列为 x = [1, 2, 4, 3]（共 4 个值），初始状态下局部最大值 m = -\infty，指数和 l = 0。

    我们分成多步来计算。

    4.1.1 第 1 步：处理 x_1 = 1¶

    • 求最大值：m_1 = \max(-\infty, x_1) = 1
    • 计算指数和：l_1 = 0 + e^{x_1 - m_1} = 0 + e^{1 - 1} = 1

    4.1.2 第 2 步：处理 x_2 = 2¶

    更新最大值：m_2 = \max(m_1, x_2) = 2 （最大值变大了！）

    我们要求的是l_2 = e^{x_1 - m_2} + e^{x_2 - m_2}。e^{x_2 - m_2}当然要计算，但是能不能利用上一步的结果避免 重复读取 x_1呢？ 我们可以用一个缩放因子：e^{m_1 - m_2}乘以l_1就可以得到我们想要的值。

    \begin{aligned} l_2 &= l_1 e^{m_1 - m_2} + e^{x_2 - m_2} \\ &= e^{x_1 - m_1} e^{m_1 - m_2} + e^{x_2 - m_2} \\ &= e^{x_1 - m_2} + e^{x_2 - m_2} \end{aligned}

    注意：我们的重点不是减少计算，而是减少显存(x_1)读取。另外如果最大值没有变化，那么e^{m_1 - m_2}=e^0=1，公式也是正确的。

    4.1.3 第 3 步：处理 x_3 = 4¶

    更新最大值：m_3 = \max(m_2, x_3) = 4

    \begin{aligned} l_3 &= l_2 e^{m_2 - m_3} + e^{x_3 - m_3} \\ &= (e^{x_1 - m_2} + e^{x_2 - m_2}) \cdot e^{m_2 - m_3} + e^{x_3 - m_3} \\ &= e^{x_1 - m_3} + e^{x_2 - m_3} + e^{x_3 - m_3} \end{aligned}

    4.1.4 第 4 步：处理 x_4 = 3¶

    m_4 = \max(m_3, x_4)

    \begin{aligned} l_4 &= l_3 e^{m_3 - m_4} + e^{x_4 - m_4} \\ &= (e^{x_1 - m_3} + e^{x_2 - m_3} + e^{x_3 - m_3}) \cdot e^{m_3 - m_4} + e^{x_4 - m_4} \\ &= e^{x_1 - m_4} + e^{x_2 - m_4} + e^{x_3 - m_4} + e^{x_4 - m_4} \end{aligned}

    4.2 通用表达式并证明¶

    通过前面的例子，我们猜测，如果前i-1 个元素的全局最大值为 m_{i-1}，累积的指数和为l_{i-1}，那么通过下面的方法：

    • m_i = \max(m_{i-1}, x_i)
    • l_i = l_{i-1} e^{m_{i-1} - m_i} + e^{x_i - m_i}

    这样得到的m_i和l_i就是前i个数的最大值和指数累加和。证明过程如下：

    4.2.1. 更新最大值¶

    m_i = \max(m_{i-1}, x_i)

    这个非常明显，前i个数的最大值要么是第i个，要么是前i-1个数中的最大值。

    4.2.2. 推导新的指数和 l_i¶

    根据定义，包含前 i 个元素的新指数和应该相对于新最大值 m_i 进行归一化：

    l_i = \sum_{j=1}^{i} e^{x_j - m_i}

    我们可以把第 i 项拆出来，并将前 i-1 项的底数从旧的最大值 m_{i-1} 转换到新的最大值 m_i：

    l_i = \left( \sum_{j=1}^{i-1} e^{x_j - m_i} \right) + e^{x_i - m_i}

    利用指数律 e^{x_j - m_i} = e^{x_j - m_{i-1} + m_{i-1} - m_i} = e^{x_j - m_{i-1}} \cdot e^{m_{i-1} - m_i}，将其代入上式：

    l_i = \left( \sum_{j=1}^{i-1} e^{x_j - m_{i-1}} \cdot e^{m_{i-1} - m_i} \right) + e^{x_i - m_i}

    由于缩放因子 e^{m_{i-1} - m_i} 与求和指标 j 无关，可以将其从求和符号中提出来：

    l_i = \left( \sum_{j=1}^{i-1} e^{x_j - m_{i-1}} \right) \cdot e^{m_{i-1} - m_i} + e^{x_i - m_i}

    注意到括号内的部分正是旧的指数和 l_{i-1}：

    l_i = l_{i-1} \cdot e^{m_{i-1} - m_i} + e^{x_i - m_i}

    4.2.3 初始条件¶

    • m_1 = x_1
    • l_1 = e^{x_1 - m_1} = 1

    当然，为了写代码方便，我们通常增加一个第0步：

    • m_0 = -\infty
    • l_0 = 0

    那么显然可以从第0步推导出第1步：

    • m_1 = \max(m_0, x_1) = x_1
    • l_1 = l_0 e^{m_0 - m_1} + e^{x_1 - m_1} = 0 e^{-\infty - m_1} + e^{x_1 - m_1}

    4.3.1 online_softmax¶

    // ========================================================
// 1. Online Softmax (Single-Pass 动态修正求 Max 和 Sum)
// ========================================================
std::vector<float> online_softmax(const std::vector<float>& x) {
    if (x.empty()) return {};

    size_t n = x.size();
    std::vector<float> result(n);

    // m 代表当前的局部最大值 (m_i)
    // l 代表当前的局部指数和 (d_i)
    float m = -std::numeric_limits<float>::infinity();
    float l = 0.0f;

    // ----------------------------------------------------
    // Pass 1: 单次遍历，动态求出全局 m 和全局 d，同时计算未完全归一化的分子
    // ----------------------------------------------------
    for (size_t i = 0; i < n; ++i) {
        float m_prev = m;

        // 1. 更新最大值
        m = std::max(m_prev, x[i]);

        // 2. 计算旧指数和的缩放因子 e^(m_prev - m)
        // 注意：当 m_prev 为 -Inf 时（第一次迭代），缩放因子设为 0
        float scale = std::exp(m_prev - m);

        // 3. 动态修正旧的 sum_exp，并加上新元素的 e^(x[i] - m)
        l = l * scale + std::exp(x[i] - m);
    }

    // 此时 m 为全局最大值，l 为基于全局最大值的精确指数和 sum(e^(x_i - m))

    // ----------------------------------------------------
    // Pass 2: 归一化计算最终概率 (仅用于输出结果)
    // ----------------------------------------------------
    for (size_t i = 0; i < n; ++i) {
        result[i] = std::exp(x[i] - m) / l;
    }

    return result;
}

    # ========================================================
# 1. Online Softmax (单次遍历 动态修正求 Max 和 Sum)
# ========================================================
def online_softmax(x):
    arr = np.array(x, dtype=float)
    if arr.size == 0:
        return np.array([])

    n = arr.size
    result = np.zeros(n)

    m = -np.inf
    l = 0.0

    # 模拟单次遍历逐个元素更新（对应 C++ online_softmax）
    for i in range(n):
        val = arr[i]
        m_prev = m

        # 1. 更新最大值
        m = max(m_prev, val)

        # 2. 计算旧指数和的缩放因子 e^(m_prev - m)
        # 第一次迭代时 m_prev 为 -inf，np.exp(-inf) 为 0.0
        scale = np.exp(m_prev - m)

        # 3. 动态修正旧的 sum_exp，并加上新元素
        l = l * scale + np.exp(val - m)

    # 归一化计算最终概率
    for i in range(n):
        result[i] = np.exp(arr[i] - m) / l

    return result

    4.3.2 分支版本¶

    如果我们还记得前面的过程，如果新的最大值比原来的大，那么就需要用缩放因子修复原来的指数和，否则可以保持不变。那也可以写成下面的代码：

        for (size_t i = 0; i < n; ++i) {
        float val = x[i];

        if (val > m) {
            // 路径 A：遇到了比当前 m 更大的值！
            // 1. 计算 m 的平移增量带来的缩放因子 e^(m_old - val)
            //    注意：首次迭代时 m 是 -Inf，std::exp(-Inf) 会正确返回 0.0f
            float scale = std::exp(m - val);

            // 2. 修正旧的指数和：旧和乘以 scale，再加上当前新元素 (e^(val - val) = 1.0f)
            l = l * scale + 1.0f;

            // 3. 更新全局最大值
            m = val;
        } else {
            // 路径 B：当前值 val <= m，最大值 m 保持不变！
            // 缩放因子 scale = exp(m - m) = exp(0) = 1.0，因此旧的 l 无需做任何乘法修正
            // 只需要直接加当前元素的 e^(val - m) 即可，省下了一次 std::exp(m_old - m) 的计算
            l += std::exp(val - m);
        }
    }

    # ========================================================
# 3. Online Softmax Branching (带条件分支优化)
# ========================================================
def online_softmax_branching(x):
    arr = np.array(x, dtype=float)
    if arr.size == 0:
        return np.array([])

    n = arr.size
    result = np.zeros(n)

    m = -np.inf
    l = 0.0

    for i in range(n):
        val = arr[i]

        if val > m:
            # 路径 A：遇到了比当前 m 更大的值
            scale = np.exp(m - val)
            l = l * scale + 1.0
            m = val
        else:
            # 路径 B：当前值 val <= m，最大值保持不变
            l += np.exp(val - m)

    # 归一化计算最终概率
    for i in range(n):
        result[i] = np.exp(arr[i] - m) / l

    return result

    这样看起来好像可以减少一些不必要的计算量，那么哪个好呢？

    无分支（Branchless）的版本依然是高性能计算（如 CUDA 内核或 CPU SIMD 向量化）中的绝对首选。

    虽然直观上来看，if-else 版本巧妙地避开了当 val \le m 时的 std::exp 计算，但在现代底层硬件架构中，控制流分支带来的破坏远远超过了省下几次浮点运算的收益。具体原因体现在几个关键层面：

    4.3.2.1. GPU 架构的致命伤：Warp 分支分化（Branch Divergence）¶

    在 GPU 的 SIMT（单指令多线程）架构中，一个 Warp（32个线程）必须执行相同的指令。

    • 如果引入了 if (val > m) 分支，而 Warp 内不同的线程拿到的数据不同（有的 val > m 走路径 A，有的 val \le m 走路径 B），硬件就会发生 分支分化。
    • 此时，GPU 必须把这两条路径 串行执行——先让走路径 A 的线程干活（路径 B 的线程挂起），然后再反过来。这会让该循环的硬件吞吐量直接折半甚至暴跌。
    • 而无分支版本保证了所有线程在每一轮循环中执行完全相同的指令流，硬件流水线可以全速运转。
    4.3.2.2. 现代硬件对 std::exp(0) 的超强优化¶

    你可能会担心在无分支版本中，当 m 没变时，scale = std::exp(m_prev - m) 会变成 std::exp(0)，从而白白浪费算力。但实际上：

    • 在现代编译器（如 nvcc）和 GPU 的特殊功能单元（SFU）中，std::exp(0) 或极其接近 0 的数值会被高度优化。
    • 更重要的是，现代处理器的乱序执行（Out-of-Order Execution）和指令级并行（ILP）极其强大。多出一条算术或函数指令，只要没有控制流跳转（Control Hazard），就可以被后续的访存或计算指令完美掩盖（Hide Latency）。
    4.3.2.3. CPU 向量化与编译器优化（Auto-vectorization）¶

    如果这段代码跑在 CPU 上并试图利用 AVX2/AVX-512 等 SIMD 向量指令集：

    • 带有 if-else 的代码会让编译器的大多数 自动向量化优化直接失效。编译器无法把一个充满条件跳转的循环打包成一条宽向量指令。
    • 无分支版本则通常可以被编译器重写为条件移动指令（如 x86 的 CMOV 或 ARM 的条件选择），或者通过数学技巧（如掩码操作）保持纯粹的直线型代码，实现 SIMD 并行。
    4.3.3.4. 结论¶

    在编写高性能算子时，“消除分支、保持代码呈直线型（Straight-line Code）”永远是第一优先级。宁可多执行一条微不足道的 exp，也绝对不能让 if-else 破坏硬件的流水线和线程同步。

    5. Block Online Softmax¶

    上面的代码一次处理一个输入，对于GPU或者有向量指令集的CPU来说是低效的。我们可以一次处理一个块，求这个块的最大元素，然后用这个最大值去计算缩放因子进行修正，并且用它计算新的指数和。可以证明，它最终的计算结果也是正确的。

    std::vector<float> block_online_softmax(const std::vector<float>& x, size_t block_size) {
    if (x.empty()) return {};

    size_t n = x.size();
    std::vector<float> result(n);

    float m = -std::numeric_limits<float>::infinity();
    float l = 0.0f;

    // ----------------------------------------------------
    // Pass 1: 分块（Tile-based）遍历，每次处理一个 block_size 大小的分块
    // ----------------------------------------------------
    for (size_t i = 0; i < n; i += block_size) {
        size_t current_block_size = std::min(block_size, n - i);

        // 1. 找出当前 Block 内的局部最大值 m_block
        float m_block = -std::numeric_limits<float>::infinity();
        for (size_t j = 0; j < current_block_size; ++j) {
            m_block = std::max(m_block, x[i + j]);
        }

        // 2. 结合历史全局最大值 m，更新出当前步骤的新全局最大值
        float m_prev = m;
        m = std::max(m_prev, m_block);

        // 3. 计算旧指数和的缩放因子
        float scale_prev = std::exp(m_prev - m);

        // 4. 计算当前 Block 内所有元素相对于新全局最大值 m 的指数和
        float l_block = 0.0f;
        for (size_t j = 0; j < current_block_size; ++j) {
            l_block += std::exp(x[i + j] - m);
        }

        // 5. 动态更新全局指数和：旧和缩放 + 当前块指数和
        l = l * scale_prev + l_block;
    }

    // ----------------------------------------------------
    // Pass 2: 归一化计算最终概率
    // ----------------------------------------------------
    for (size_t i = 0; i < n; ++i) {
        result[i] = std::exp(x[i] - m) / l;
    }

    return result;
}

    # ========================================================
# 4. Block Online Softmax (分块 Online Softmax，GPU/Triton 常用)
# ========================================================
def block_online_softmax(x, block_size):
    arr = np.array(x, dtype=float)
    if arr.size == 0:
        return np.array([])

    n = arr.size
    result = np.zeros(n)

    m = -np.inf
    l = 0.0

    # Pass 1: 按 block_size 分块遍历（模拟硬件 SRAM / Block 级并行）
    for i in range(0, n, block_size):
        block = arr[i : i + block_size]

        # 1. 找出当前 Block 内的局部最大值
        m_block = np.max(block)

        # 2. 结合历史全局最大值 m，更新出当前步骤的新全局最大值
        m_prev = m
        m = max(m_prev, m_block)

        # 3. 计算旧指数和的缩放因子
        scale_prev = np.exp(m_prev - m)

        # 4. 计算当前 Block 内所有元素相对于新全局最大值 m 的指数和
        l_block = np.sum(np.exp(block - m))

        # 5. 动态更新全局指数和
        l = l * scale_prev + l_block

    # Pass 2: 归一化计算最终概率
    for i in range(n):
        result[i] = np.exp(arr[i] - m) / l

    return result

    6. Online Softmax并且乘以一个向量¶

    回顾一下，我们的Attention计算。

    O = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V

    它不仅仅计算一个Softmax，还要乘以一个向量V。我们改成Online Softmax之后对于输出O的处理也需要进行类似的缩放修复。

    具体来说，我们需要：

    • 第一步计算：

      O_1 = V_1

    • 第二步计算：

      O_2 = \frac{e^{x_1-m_2}}{e^{x_1-m_2} + e^{x_2-m_2}} V_1 + \frac{e^{x_2-m_2}}{e^{x_1-m_2} + e^{x_2-m_2}} V_2

      其中分母就是l_2

    • 第三步计算：

      O_3 = \frac{e^{x_1-m_3}}{e^{x_1-m_3} + e^{x_2-m_3} + e^{x_3-m_3}} V_1 + \frac{e^{x_2-m_3}}{e^{x_1-m_3} + e^{x_2-m_3} + e^{x_3-m_3}} V_2 + \frac{e^{x_3-m_3}}{e^{x_1-m_3} + e^{x_2-m_3} + e^{x_3-m_3}} V_3

      其中分母就是l_3

    6.1 递推公式¶

    初始值：

    • m_0 = -\infty
    • l_0 = 0
    • O_0 = 0

    从第i-1步到第i步：

    • m_i = \max(m_{i-1}, x_i)
    • l_i = l_{i-1} e^{m_{i-1} - m_i} + e^{x_i - m_i}
    • O_i = \frac{l_{i-1}}{l_i} e^{m_{i-1} - m_i}O_{i-1} + \frac{e^{x_i - m_i}}{l_i}V_i

    6.2 递推公式验证¶

    我们可以简单的验证一下从第2步到第3步是正确的。

    为了验证从第 2 步到第 3 步（即利用 m_2, l_2, O_2 推导 O_3）的正确性，我们可以直接从前 3 个元素的目标定义出发进行全景展开。

    6.2.1. 目标定义（直接从定义出发）¶

    对于前 3 个元素 x_1, x_2, x_3 及其对应的值 V_1, V_2, V_3，全局最大值为 m_3 = \max(x_1, x_2, x_3)，总指数和分母为：

    l_3 = e^{x_1 - m_3} + e^{x_2 - m_3} + e^{x_3 - m_3}

    最终的输出 O_3 按定义应为：

    O_3 = \frac{e^{x_1 - m_3} V_1 + e^{x_2 - m_3} V_2 + e^{x_3 - m_3} V_3}{l_3}

    6.2.2. 利用递推关系进行代数变形¶

    我们将分子中的前两项与最后一项拆开，并通过指数律引入第 2 步的全局最大值 m_2 = \max(x_1, x_2)：

    分子可以改写为：

    \text{分子} = \left( e^{x_1 - m_3} V_1 + e^{x_2 - m_3} V_2 \right) + e^{x_3 - m_3} V_3

    对前两项提取公因式 e^{m_2 - m_3}：

    e^{x_1 - m_3} V_1 + e^{x_2 - m_3} V_2 = \left( e^{x_1 - m_2} V_1 + e^{x_2 - m_2} V_2 \right) e^{m_2 - m_3}

    根据第 2 步的定义，括号内的部分正好等于 l_2 O_2（因为 l_2 = e^{x_1 - m_2} + e^{x_2 - m_2}）：

    e^{x_1 - m_2} V_1 + e^{x_2 - m_2} V_2 = l_2 O_2

    因此，整个分子可以代换为：

    \text{分子} = l_2 e^{m_2 - m_3} O_2 + e^{x_3 - m_3} V_3

    6.2.3. 代回 O_3 表达式¶

    将变形后的分子除以分母 l_3：

    O_3 = \frac{l_2 e^{m_2 - m_3} O_2 + e^{x_3 - m_3} V_3}{l_3} = \frac{l_2}{l_3} e^{m_2 - m_3} O_2 + \frac{e^{x_3 - m_3}}{l_3} V_3

    这与递推公式完全一致，从而验证了从第 2 步过渡到第 3 步（以及任意 i-1 \to i）的数学正确性。

    6.3 递推公式证明¶

    6.3.1. 定义第 i 步的输出 O_i¶

    根据 Online Softmax 的定义，第 i 步的归一化输出（或加权值累加结果）是以当前全局最大值 m_i 为基准计算的：

    O_i = \sum_{j=1}^{i} \frac{e^{x_j - m_i}}{l_i} V_j = \frac{1}{l_i} \sum_{j=1}^{i} e^{x_j - m_i} V_j

    6.3.2. 拆分求和项¶

    将前 i 项的和拆分为“前 i-1 项”和“第 i 项”：

    O_i = \frac{1}{l_i} \left( \sum_{j=1}^{i-1} e^{x_j - m_i} V_j + e^{x_i - m_i} V_i \right)

    6.3.3. 利用指数律转换基准¶

    对于前 i-1 项中的每一项，将其指数基准从新的最大值 m_i 转换回旧的最大值 m_{i-1}：

    e^{x_j - m_i} = e^{(x_j - m_{i-1}) + (m_{i-1} - m_i)} = e^{x_j - m_{i-1}} \cdot e^{m_{i-1} - m_i}

    将此代入上式：

    O_i = \frac{1}{l_i} \left( e^{m_{i-1} - m_i} \sum_{j=1}^{i-1} e^{x_j - m_{i-1}} V_j + e^{x_i - m_i} V_i \right)

    6.3.4. 代入上一轮的累积结果¶

    根据第 i-1 步的定义，旧的归一化输出为：

    O_{i-1} = \frac{1}{l_{i-1}} \sum_{j=1}^{i-1} e^{x_j - m_{i-1}} V_j \implies \sum_{j=1}^{i-1} e^{x_j - m_{i-1}} V_j = l_{i-1} O_{i-1}

    将 \sum_{j=1}^{i-1} e^{x_j - m_{i-1}} V_j = l_{i-1} O_{i-1} 代入 O_i 的表达式中：

    O_i = \frac{1}{l_i} \left( e^{m_{i-1} - m_i} \cdot l_{i-1} O_{i-1} + e^{x_i - m_i} V_i \right)

    6.3.5. 整理得到最终递推式¶

    展开并重新排列各项：

    O_i = \frac{l_{i-1} e^{m_{i-1} - m_i}}{l_i} O_{i-1} + \frac{e^{x_i - m_i}}{l_i} V_i

    6.4 代码实现¶

    std::vector<float> online_softmax_normed_output(
    const std::vector<float>& logits,
    const std::vector<std::vector<float>>& values) 
{
    size_t n = logits.size();
    if (n == 0 || values.empty()) return {};
    size_t vec_dim = values[0].size();

    float m = -std::numeric_limits<float>::infinity(); // 局部 Max
    float l = 0.0f;                                     // 局部 Sum Exp

    // O 始终保持为“已归一化”的向量，初始全 0
    std::vector<float> O(vec_dim, 0.0f);

    for (size_t i = 0; i < n; ++i) {
        float x_i = logits[i];
        const auto& v_i = values[i];

        float m_prev = m;
        m = std::max(m_prev, x_i);

        // 1. 计算缩放因子与新元素的未归一化权重
        float scale = std::exp(m_prev - m);
        float w_i = std::exp(x_i - m);

        // 2. 更新新的分母 d_new
        float l_prev = l;
        l = l_prev * scale + w_i;

        // 3. 动态递推更新已经归一化的 O 向量
        // alpha 为旧 O 向量的保留权重，beta 为新 v_i 向量的混合权重
        float alpha = (l_prev * scale) / l;  // 当 i=0 (d_prev=0) 时，alpha 恰好为 0
        float beta = w_i / l;

        for (size_t j = 0; j < vec_dim; ++j) {
            // 直接在线更新已归一化的结果，无需在循环外除以 l
            O[j] = alpha * O[j] + beta * v_i[j];
        }
    }

    // 循环结束时，O 已经是完全归一化后的最终结果！
    return O;
}

    values = np.array(values, dtype=float)

    if n == 0 or values.size == 0:

        v_i = values[i]

    6.5 优化：最后再做归一化¶

    我们上面的实现里，每次计算的O_i都是除以了当前累加和以归一化。但是我们在下一步计算的时候又乘以了上一步的累加和l_{i-1}把它变成未归一化的值，缩放修正后又用新的累加和l_i重新归一化。其实我们可以省略掉归一化，在最后的时候再归一化，这样可以把归一化的次数从n减少到1次，而且还可以省掉一个局部变量l_prev(l_{i-1})。

    6.5.1 递推公式¶

    首先我们引入未归一化的输出\tilde{O}，它的值是：

    \tilde{O}_i = \sum_{j=1}^i e^{x_j - m_i} V_j

    把它除以l_i就可以得到O_i。

    初始值：

    • m_0 = -\infty
    • l_0 = 0
    • O_0 = 0(保留下来只是为了对比，代码里可以删除)
    • \tilde{O}_0 = 0

    从第i-1步到第i步：

    • m_i = \max(m_{i-1}, x_i)
    • l_i = l_{i-1} e^{m_{i-1} - m_i} + e^{x_i - m_i}
    • O_i = \frac{l_{i-1}}{l_i} e^{m_{i-1} - m_i}O_{i-1} + \frac{e^{x_i - m_i}}{l_i}V_i (保留下来只是为了对比，代码里可以删除)
    • \tilde{O}_i = e^{m_{i-1} - m_i}\tilde{O}_{i-1} + e^{x_i - m_i}V_i

    6.5.2 递推公式的证明¶

    6.5.2.1. 展开定义¶

    根据未归一化输出 \tilde{O}_i 的定义，将其写出求和形式：

    \tilde{O}_i = \sum_{j=1}^{i} e^{x_j - m_i} V_j
    6.5.2.2. 拆分求和项¶

    将求和区间拆分为“前 i-1 项”和“第 i 项”：

    \tilde{O}_i = \left( \sum_{j=1}^{i-1} e^{x_j - m_i} V_j \right) + e^{x_i - m_i} V_i
    6.5.2.3. 利用指数律转换基准¶

    对于前 i-1 项，将当前的全局最大值基准从 m_i 转换回上一轮的全局最大值 m_{i-1}：

    e^{x_j - m_i} = e^{(x_j - m_{i-1}) + (m_{i-1} - m_i)} = e^{x_j - m_{i-1}} \cdot e^{m_{i-1} - m_i}

    将上式代入前 i-1 项的求和中：

    \tilde{O}_i = \left( \sum_{j=1}^{i-1} e^{x_j - m_{i-1}} e^{m_{i-1} - m_i} V_j \right) + e^{x_i - m_i} V_i
    6.5.2.4. 提取公因式并代入 \tilde{O}_{i-1}¶

    由于 e^{m_{i-1} - m_i} 与求和变量 j 无关，可以将其提到求和符号外面：

    \tilde{O}_i = e^{m_{i-1} - m_i} \left( \sum_{j=1}^{i-1} e^{x_j - m_{i-1}} V_j \right) + e^{x_i - m_i} V_i

    根据 \tilde{O}_{i-1} 的定义，括号内的部分正好就是 \tilde{O}_{i-1}：

    \tilde{O}_{i-1} = \sum_{j=1}^{i-1} e^{x_j - m_{i-1}} V_j

    将其代入，即得到最终的递推公式：

    \tilde{O}_i = e^{m_{i-1} - m_i} \tilde{O}_{i-1} + e^{x_i - m_i} V_i

    代码实现优势： 引入未归一化输出 \tilde{O}_i 后，在循环迭代过程中只需要维护一个累加变量，完全不需要在每一步都除以 l_i。所有的缩放和累加都在未归一化空间中进行，直到整个循环结束、求出最终的全局 l_n 后，在最后一步统一执行一次归一化（O_n = \tilde{O}_n / l_n），这在工程实现上极大地减少了浮点除法指令的开销，并保证了数值稳定性。

    6.5.3 代码实现¶

    std::vector<float> online_softmax_unnormed_output(
    const std::vector<float>& logits,
    const std::vector<std::vector<float>>& values) 
{
    size_t n = logits.size();
    if (n == 0 || values.empty()) return {};
    size_t vec_dim = values[0].size();

    // 1. 初始化统计量与未归一化的累加向量 O_unnorm
    float m = -std::numeric_limits<float>::infinity(); // 局部 Max
    float l = 0.0f;                                     // 局部 Sum Exp
    std::vector<float> O_unnorm(vec_dim, 0.0f);        // 未归一化的输出向量分子

    // ---------------------------------------------------------------------
    // Single-Pass 遍历：一次循环同步完成 Max 更新、Exp 修正与向量累加
    // ---------------------------------------------------------------------
    for (size_t i = 0; i < n; ++i) {
        float x_i = logits[i];
        const auto& v_i = values[i];

        float m_prev = m;
        m = std::max(m_prev, x_i);

        // 计算修正缩放因子
        float scale = std::exp(m_prev - m);
        float w_i = std::exp(x_i - m);

        // A. 动态更新分母 d
        l = l * scale + w_i;

        // B. 动态更新分子向量 O_unnorm:
        //    旧的分子向量按 scale 缩放，并叠加当前新向量 w_i * v_i
        for (size_t j = 0; j < vec_dim; ++j) {
            O_unnorm[j] = O_unnorm[j] * scale + w_i * v_i[j];
        }
    }

    // ---------------------------------------------------------------------
    // 最终归一化：将累加向量分子除以全局分母 d
    // ---------------------------------------------------------------------
    std::vector<float> O(vec_dim, 0.0f);
    for (size_t j = 0; j < vec_dim; ++j) {
        O[j] = O_unnorm[j] / l;
    }

    return O;
}

    # ========================================================
# 2. 在线未归一化输出（FlashAttention 经典做法：先攒分子，最后除分母）
# ========================================================
def online_softmax_unnormed_output(logits, values):
    logits = np.array(logits, dtype=float)
    values = np.array(values, dtype=float)

    n = logits.size
    if n == 0 or values.size == 0:
        return np.array([])

    vec_dim = values.shape[1]

    m = -np.inf  # 局部 Max
    l = 0.0      # 局部 Sum Exp
    O_unnorm = np.zeros(vec_dim, dtype=float)  # 未归一化的输出向量分子

    for i in range(n):
        x_i = logits[i]
        v_i = values[i]

        m_prev = m
        m = max(m_prev, x_i)

        # 计算修正缩放因子
        scale = np.exp(m_prev - m)
        w_i = np.exp(x_i - m)

        # A. 动态更新分母 l
        l = l * scale + w_i

        # B. 动态更新分子向量 O_unnorm
        O_unnorm = O_unnorm * scale + w_i * v_i

    # 最终归一化：将累加向量分子除以全局分母 l
    O = O_unnorm / l if l != 0 else O_unnorm
    return O

    可以看到，我们在循环结束后，用最后的l_n去做归一化，就可以得到正确的O。

    说明：FlashAttention v1使用的是归一化的算法，而FlashAttention v2使用的是未归一化(最后归一化)的算法。
